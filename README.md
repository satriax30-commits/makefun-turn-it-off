# Have You Tried Turning It Off?

A deterministic Node 22 program that writes one funny line a hopeless tech support agent says to a desperate customer — twisting the classic "turn it off and on again" onto the customer instead of the device.

## Run it

```sh
node main.ts output
```

This writes the entry to `output/entry.txt` (1–199 chars, single line, no trailing newline), validated before and after writing.
